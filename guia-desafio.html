Onde este projeto difere da aula
  • A base criada pelo Console é do tipo Bedrock Managed, que não aceita retrieve_and_generate. O RAG foi refeito em duas chamadas: retrieve + converse (Fase 4).

bedrock_runtime = session.client(service_name='bedrock-runtime')

def generate_embedding(text):
    body = json.dumps({"inputText": text})
    response = bedrock_runtime.invoke_model(
        modelId="amazon.titan-embed-text-v2:0",
        body=body,
        contentType="application/json",
        accept="application/json"
    )
    result = json.loads(response["body"].read())
    return result["embedding"]

4.2

Escrever a função ask

NOTEBOOK
Por quê A base managed não aceita a chamada única retrieve_and_generate da aula. Separar busca e geração resolve, e ainda mostra cada etapa do RAG.
Célula do notebook
def ask(question, n_resultados=5):
    # 1. Retrieval: base managed usa managedSearchConfiguration
    retrieval = bedrock_agent_runtime.retrieve(
        knowledgeBaseId=Knowledge_Base_ID,
        retrievalQuery={"text": question},
        retrievalConfiguration={
            "managedSearchConfiguration": {"numberOfResults": n_resultados}
        }
    )
    resultados = retrieval["retrievalResults"]
    trechos = [r["content"]["text"] for r in resultados]
    contexto = "\n\n".join(trechos)

    # 2. Generation: o modelo responde usando apenas o contexto recuperado
    prompt = (
        "Responda à pergunta usando somente as informações do contexto abaixo. "
        "Se a resposta não estiver no contexto, diga que não sabe.\n\n"
        f"Contexto:\n{contexto}\n\nPergunta: {question}"
    )
    response = bedrock_runtime.converse(
        modelId=Model_ID,
        messages=[{"role": "user", "content": [{"text": prompt}]}],
        inferenceConfig={"maxTokens": 512, "temperature": 0.2}
    )
    texto_resposta = response["output"]["message"]["content"][0]["text"]

    # 3. Citações no mesmo formato do retrieve_and_generate
    citations = [{
        "generatedResponsePart": {"textResponsePart": {"text": texto_resposta}},
        "retrievedReferences": [
            {"content": r["content"], "location": r.get("location"),
             "metadata": r.get("metadata", {}), "score": r.get("score")}
            for r in resultados
        ]
    }]

    return {"output": {"text": texto_resposta}, "citations": citations, "trechos": trechos}

import csv
from pathlib import Path

import boto3
import streamlit as st
from botocore.exceptions import BotoCoreError, ClientError

# ------------------------------------------------------------------
# 1. Configurações (as mesmas do notebook de RAG)
# ------------------------------------------------------------------
KNOWLEDGE_BASE_ID = "4SCLDZ9ZTH"
MODEL_ID = "us.amazon.nova-micro-v1:0"
REGION = "us-east-1"
# O CSV de credenciais fica na mesma pasta do app.py (fora do código)
ARQUIVO_CREDENCIAIS = Path(__file__).parent / "curso_bedrock_accessKeys.csv"

st.set_page_config(
    page_title="Assistente IA Expert Academy",
    page_icon="🤖",
    layout="wide"
)


# ------------------------------------------------------------------
# 2. Conexão com a AWS
# ------------------------------------------------------------------
# O Streamlit reexecuta o script a cada interação. O cache_resource
# faz os clientes serem criados uma única vez e reaproveitados.
@st.cache_resource
def criar_clientes():
    with open(ARQUIVO_CREDENCIAIS, encoding="utf-8-sig") as f:
        credenciais = next(csv.DictReader(f))

    session = boto3.Session(
        aws_access_key_id=credenciais["Access key ID"],
        aws_secret_access_key=credenciais["Secret access key"],
        region_name=REGION,
    )
    # bedrock-agent-runtime: busca na Knowledge Base | bedrock-runtime: geração da resposta
    return session.client("bedrock-agent-runtime"), session.client("bedrock-runtime")


# ------------------------------------------------------------------
# 3. RAG em duas etapas: busca + geração
# ------------------------------------------------------------------
def ask(question, n_resultados=5, temperature=0.2):
    bedrock_agent_runtime, bedrock_runtime = criar_clientes()

    # Retrieval: a base é "Bedrock Managed", por isso usa managedSearchConfiguration
    retrieval = bedrock_agent_runtime.retrieve(
        knowledgeBaseId=KNOWLEDGE_BASE_ID,
        retrievalQuery={"text": question},
        retrievalConfiguration={
            "managedSearchConfiguration": {"numberOfResults": n_resultados}
        }
    )
    resultados = retrieval["retrievalResults"]

    # Sem trechos encontrados não há contexto, então nem chamamos o modelo
    if not resultados:
        return {
            "resposta": "Não encontrei informações sobre isso na base de conhecimento.",
            "fontes": []
        }

    contexto = "\n\n".join(r["content"]["text"] for r in resultados)

    # Generation: o modelo responde usando apenas o contexto recuperado
    prompt = (
        "Responda à pergunta usando somente as informações do contexto abaixo. "
        "Se a resposta não estiver no contexto, diga que não sabe.\n\n"
        f"Contexto:\n{contexto}\n\nPergunta: {question}"
    )
    response = bedrock_runtime.converse(
        modelId=MODEL_ID,
        messages=[{"role": "user", "content": [{"text": prompt}]}],
        inferenceConfig={"maxTokens": 512, "temperature": temperature}
    )

    return {
        "resposta": response["output"]["message"]["content"][0]["text"],
        "fontes": resultados
    }


# ------------------------------------------------------------------
# 4. Exibição das fontes (citações)
# ------------------------------------------------------------------
def mostrar_fontes(fontes):
    if not fontes:
        return

    with st.expander(f"📄 Fontes ({len(fontes)} trechos)"):
        for i, fonte in enumerate(fontes, start=1):
            uri = (fonte.get("location") or {}).get("s3Location", {}).get("uri", "")
            arquivo = uri.rsplit("/", 1)[-1] if uri else "documento"
            pagina = (fonte.get("metadata") or {}).get("x-amz-bedrock-kb-document-page-number")
            score = fonte.get("score")

            titulo = f"**Trecho {i}** · {arquivo}"
            if pagina is not None:
                titulo += f" · página {int(float(pagina))}"
            if score is not None:
                titulo += f" · score {score:.3f}"

            st.markdown(titulo)
            st.caption(fonte["content"]["text"])


# ------------------------------------------------------------------
# 5. Interface
# ------------------------------------------------------------------
st.title("🤖 Assistente IA Expert Academy")
st.caption("Pergunte sobre cursos, trilhas, planos e termos de uso da IA Expert Academy.")

# O histórico fica no session_state para sobreviver às reexecuções do script
if "messages" not in st.session_state:
    st.session_state.messages = []

with st.sidebar:
    st.header("⚙️ Configurações")
    n_resultados = st.slider("Trechos buscados na base", min_value=1, max_value=10, value=5)
    temperature = st.slider("Temperature", min_value=0.0, max_value=1.0, value=0.2, step=0.1)

    if st.button("🗑️ Limpar conversa"):
        st.session_state.messages = []
        st.rerun()

    st.divider()
    st.caption(f"Base de conhecimento: `{KNOWLEDGE_BASE_ID}`  \nModelo: `{MODEL_ID}`")

# Reexibe o histórico da conversa
for message in st.session_state.messages:
    with st.chat_message(message["role"]):
        st.markdown(message["content"])
        mostrar_fontes(message.get("fontes"))

if prompt := st.chat_input("Digite sua pergunta"):
    # Usuário
    st.session_state.messages.append({"role": "user", "content": prompt})
    with st.chat_message("user"):
        st.markdown(prompt)

    # Assistente
    with st.chat_message("assistant"):
        with st.spinner("Consultando a base de conhecimento..."):
            try:
                resultado = ask(prompt, n_resultados=n_resultados, temperature=temperature)
            except FileNotFoundError:
                st.error(f"Arquivo de credenciais não encontrado: `{ARQUIVO_CREDENCIAIS.name}`")
            except (ClientError, BotoCoreError) as erro:
                st.error(f"Erro ao consultar a AWS: {erro}")
            else:
                st.markdown(resultado["resposta"])
                mostrar_fontes(resultado["fontes"])
                st.session_state.messages.append({
                    "role": "assistant",
                    "content": resultado["resposta"],
                    "fontes": resultado["fontes"]
                })
PeçaPara que serve
st.session_stateO Streamlit reexecuta o script a cada interação; o histórico do chat sobrevive aqui.
@st.cache_resourceCria os clientes da AWS uma única vez.
st.chat_input / st.chat_messageCampo de pergunta e balões do chat.
st.expanderMostra as fontes: arquivo, página, score e texto.
try / except + st.errorErro da AWS vira mensagem na tela, em vez de quebrar a aplicação.

Rodar a interface

TERMINAL
Por quê O Streamlit é um servidor web que fica rodando: pelo notebook, a célula ficaria travada. Por isso ele roda no terminal.
No terminal, na pasta do projeto
> python -m streamlit run app.py
Resposta esperada
You can now view your Streamlit app in your browser.
Local URL: http://localhost:8501
Armadilha comum 
'streamlit' não é reconhecido como um comando interno ou externo

O %pip instalou o Streamlit na pasta do usuário (AppData\Roaming\Python\...\Scripts), que não está no PATH do Windows. Com python -m streamlit, o Python encontra o módulo direto.

FASE 6

Limpeza: apagar o que custa e o que é risco

A base managed cobra pelo armazenamento, e a chave de acesso é um risco enquanto existir. Apague na ordem: base, bucket e, por último, a chave.

Arquitetura · o que esta fase remove
permanece■ removido nesta fase■ deixa de funcionar
Custos

Base managed: cerca de US$ 5 por GB por mês de armazenamento (com ~0,2 MB de PDFs, menos de 1 centavo), mais as buscas e os tokens dos modelos por uso. Este projeto não cria OpenSearch Serverless nem Provisioned Throughput, os recursos que cobram por hora.

Por que nesta ordem

A base lê o bucket, então sai primeiro. A chave sai por último, porque é ela que os notebooks usam para acessar a AWS (o notebook RAG, seção 11, também apaga a base e o bucket por código).
